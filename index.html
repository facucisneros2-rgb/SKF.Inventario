Pasos de configuración inicial
Realizá esto una sola vez para habilitar el backend compartido
1
Crear Google Sheet
Abrí Google Sheets → Nuevo → Nombralo "SKF Inventario CoMo"
2
Cargar Apps Script
Extensiones → Apps Script → pegá el contenido del archivo .js descargado → Guardar
3
Implementar como Web App
Implementar → Nueva implementación → App web | Ejecutar como: Yo | Acceso: Cualquier usuario de Google → Copiar URL
4
Pegar URL y probar conexión
Pegá la URL en el campo de arriba → Guardar → Probar conexión
Cargar datos iniciales
Importá el inventario desde JSON o cargá datos de demostración
Formato: array de objetos con campos Codigo, Descripcion, Categoria, StockActual, StockMinimo, Unidad
